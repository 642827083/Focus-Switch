# Focus Switch

Focus Switch（原名 Focus Next）是 MarginNote 的脑图卡片焦点切换插件，作者为乔木Joe。

当前正式版本为 Focus Switch 1.0.10，保留插件身份和已有设置。

1.0.10 新增图标展示、集中显示及横竖排列，缩小图标按钮并更新查看原题图标；折叠评论改为保留正文第一项，移除显示卡片序号功能。

1.0.8 新增“查看原题”，支持选中或进入导入题卡焦点后，打开对应题库插件并定位原题；关闭焦点切换总开关时隐藏全部浮动按钮。

插件打开后，在脑图学习界面两侧显示“上一张”和“下一张”按钮。用户双击进入任意脑图卡片焦点后，插件会持续读取并记住宿主当前焦点；点击按钮会进入相邻的同级脑图卡片焦点，并定位、高亮目标卡片，不需要再次手动点击卡片。到同级第一张或最后一张时会停留并提示。

“下一张”默认位于学习界面右侧垂直居中位置，使用蓝色样式；按钮支持自由拖动，位置会自动保存并在下次打开学习界面时恢复。

单击插件图标显示或关闭宽约 340 点的窄设置面板，双击切换插件开启／关闭。单击等待约 0.3 秒以识别双击，双击不先弹出菜单；菜单有关闭按钮，高度不足时可滚动。关闭焦点切换会移除全部浮动按钮，包括查看原题；各子开关与按钮位置保留，重新开启时恢复。

拖动菜单标题栏可移动窄面板，松手后自动保存位置，下次打开或重启插件时恢复。位置按可移动区域的比例保存，横竖屏和分屏变化时限制在可见区域内；关闭按钮、开关与滚动区域各自保持原有操作。

菜单设置均保存在 `NSUserDefaults` 中：

- **启用焦点切换**：插件总开关，沿用旧开关状态，首次使用默认开启；关闭时隐藏全部浮动按钮。
- **图标展示**：默认关闭。开启后将五个浮动按钮切换为上下箭头、取景框加放大镜、折叠和展开图标，使用 36 × 36 点按钮与 24 点图标；关闭后恢复文字。显示开关及位置记忆继续生效。
- **集中显示**：默认关闭。开启后将已启用的按钮组合为工具条，拖动任意按钮或工具条空隙可移动整组；关闭后恢复独立按钮及原来保存的位置。
- **排列方向**：可直接选择“竖向”或“横向”，默认竖向，仅在集中显示时生效。两种排列分别记住整组位置；分屏空间不足时按所选方向换行或换列，不收纳按钮。文字和图标模式均可配合集中显示。
- **跨层级切换**：默认关闭，仅切换同级兄弟；开启后按当前脑图前序深度优先顺序前进、严格逆序后退，包含父子卡片，树首尾停止。
- **显示上一张**：默认开启。关闭后保留下一张导航按钮，恢复开启时沿用原来保存的位置。
- **查看原题**：默认关闭，总开关开启时显示“查看原题”浮动按钮，可拖动并记住位置。选中 Daguanyuan、Yankean 或 Jifengjincao 导入题卡，或进入题卡焦点后点击，打开对应插件面板并定位原题；选中卡片优先于当前焦点。
- **显示折叠评论**：默认开启，显示折叠按钮，保留每张目标卡片正文第一项（不计标题）；有文字或图片主摘录时折叠全部评论，没有主摘录时保留第一条评论展开，折叠后续评论。
- **显示展开评论**：默认开启，显示展开按钮，展开每张目标卡片的全部评论。

图标展示、集中显示和排列方向位于总开关下方，打开面板即可访问。

查看原题复用导入题卡评论里的插件链接，需安装并启用对应 Bridge 插件及其依赖。普通卡片、缺失或无效链接、多个不同原题链接、题卡身份与链接冲突时提示后停止；多选时需先只选一张。旧题卡缺少插件链接时，可在来源插件中修复已导入题卡。不会改写题卡评论。

原题按钮与前后切换共用焦点读取和笔记 ID 识别逻辑，直接接收导航已识别的笔记，不再用更窄的属性检查过滤原生对象。可见焦点优先，重复读取不会退回滞后的焦点。宿主暂时清空焦点时沿用已记住的卡片；学习集 ID 可用时核对归属，宿主不提供 ID 时依靠学习集生命周期清除记忆。前后切换后同步更新该记忆，切换或关闭学习集、关闭总开关及断开场景时清除。无法识别焦点时附带“焦点检查3”诊断信息。

保留插件 ID `cn.marginnote.focus-next`、原持久化键及 `__FOCUS_NEXT_*__` 命名空间，以直接升级原插件并继承设置；Daguanyuan Bridge 的设置保持独立。

工具栏图标使用用户提供的“定位_聚点_焦点” PNG 资源。

浮动按钮的图标使用 [Lucide](https://lucide.dev/) 与 [Tabler](https://tabler.io/icons) 的本地 PNG 资源，不依赖联网加载。图标来源与转换说明见 [assets/button-icons/README.md](assets/button-icons/README.md)，授权声明随插件安装包分发。图标加载不可用时对应按钮保留文字显示。

上一张／下一张按顺序调用焦点切换和卡片定位接口，采用 MarginNote 定位后的显示效果，不锁定上一张的位置和比例。此操作无需 MN Utils，不读取或复制界面状态，不使用剪贴板。

用户在 iPad 上反馈，切换前比例大于 100% 时可能回到 100% 并出现短暂缩放；本版本保留已确认的显示效果。

进入并记住卡片焦点后，无需保持选中状态即可连续使用上一张／下一张；宿主暂时没有返回当前焦点时，沿用记住的卡片。打开其他学习集时清除记忆。

设置面板末尾显示“Focus Switch · 乔木Joe · 当前版本”的 10 点灰色小字，随选项滚动至底部可见，下方保留 14 点空隙。名称、作者与版本从安装包清单读取，正式发布时自动同步。

## 开发

1.0.9 新增支持宿主评论折叠能力的“折叠评论”和“展开评论”浮动按钮，均采用 14 点粗体并支持独立拖动和位置记忆。设置面板中的“显示折叠评论”和“显示展开评论”分别控制两个按钮，默认开启；关闭后保留各自位置和设置。选中一张或多张卡片时处理选中卡片，没有选中项时处理当前焦点卡片。1.0.10 将“折叠评论”调整为保留每张卡片正文第一项：有文字或图片主摘录时保留主摘录、折叠全部评论；没有主摘录时将第一条评论展开、折叠后续评论，第一条可以是文字、图片、手写或其他评论格式，标题不计入正文项。“展开评论”展开全部评论，图片和无文字评论也按原有顺序计数。零条或一条评论的卡片同样可处理。总开关关闭后隐藏这两个按钮。

评论操作直接调用数据库卡片的 `commentState()` 与 `setCommentsCollapsed(targets, collapsed, revision)`，无需场景网页面板，也不依赖 MN Utils 或 MNCommentManager。原生接口由宿主管理保存、撤销与刷新；插件检查 `ok`、`persisted`、版本及目标状态，并重新读取确认结果。多选时逐张处理，每批最多 200 条评论，中途失败会报告已完成的卡片数量；已完成的改动保留。切换学习集、场景失活或关闭对应开关会停止后续批次。

接口依据为用户提供的 [MNCommentManager 原生适配源码](https://github.com/xkwxdyy/MNCommentManager/blob/main/src/CommentFoldState.js)及其归档的 [MarginNote Comment 折叠接口接入指南](https://github.com/xkwxdyy/MNCommentManager/blob/main/Resources/comment-fold/MarginNote%20Comment%20%E6%8A%98%E5%8F%A0%E6%8E%A5%E5%8F%A3%E6%8E%A5%E5%85%A5%E6%8C%87%E5%8D%97.md)。当前实现依据原生接口契约独立编写，不调用其他插件的私有全局对象。

用户已在 4.5.0 build 62 上使用 MNCommentManager 验证原生折叠能力；本插件按这组原生接口适配，评论功能是否可用取决于宿主实际提供的能力。

```powershell
npm test
npm run build
```

`npm run build` 只生成开发测试包 `Focus Switch Test.mnaddon`。真机验证前，不能把内部脑图对象或定位接口视为长期稳定 API。

`npm run build:release` 生成 `Focus Switch-v<版本号>.mnaddon`，同名正式包存在时拒绝覆盖；测试确认并明确正式版本号后才构建正式包。

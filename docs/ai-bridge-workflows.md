# AI Bridge 工作流联动

Focus Switch 从 1.1.4 起支持工作流菜单，需在当前学习场景中同时启用支持联动的 AI Bridge 版本。先在 AI Bridge 的“设置 → 工作流”保存流程，再开启 Focus Switch 的“问 AI”。当前配套联动测试包为 `Ai Bridge Test.mnaddon`（内部版本 1.0.3）；仅安装同号旧正式版不代表支持此协议，AI Bridge 后续正式版本以其发布说明为准。

点击“问 AI”展开菜单，第一项“题库网站问 AI”保留原有入口；其他项显示 AI Bridge 的工作流名称和目标网站，按工作流库排序，可滚动。选择后由 AI Bridge 打开对应网站，按工作流读取卡片和手写、填入提示词与附件，用户检查后自行发送。普通卡片和当前焦点也可使用工作流，不需要原题链接。只有提示词的工作流无需选卡。

网站入口下方以细分隔线及“AI Bridge 工作流”标题分组。横向集中布局时，面板右边缘对齐最右侧可见按钮；关闭折叠、展开评论后即对齐“问 AI”。优先在工具栏下方展开，下方高度不足时改在上方；其他布局仍优先在旁边展开。面板避开可见浮动按钮及整组工具栏，窗口缩小或工具栏位于边缘时自动调整位置和大小，长列表保留滚动。

工具栏避让依据插件自身的集中／分散布局状态，统一使用学习视图中的坐标，不使用原生 `superview` 包装对象的 `===` 比较；测试覆盖同一原生父视图对应不同 JS 包装对象时的横向避让。

打开列表不上传内容、不改变工作流设置。AI Bridge 未安装、未启用或版本不支持时在菜单内提示，网站入口仍可选择。关闭菜单、切换卡片或学习集、关闭开关、拖动和场景失活会取消待选择操作；列表更新或打开超过一分钟后需要重新打开。

## 对外通知协议 v1

两个插件使用官方 `NSNotificationCenter`，不调用对方的私有全局变量，也不直接读取对方的工作流文件。

- 请求：`cn.marginnote.ai-bridge.workflow.request.v1`。
- 响应：`cn.marginnote.ai-bridge.workflow.response.v1`。
- `object` 为当前原生学习窗口；`userInfo.payload` 为 JSON 字符串。
- 公共字段为 `version: 1` 和一次性 `requestId`，响应按窗口及请求 ID 匹配。
- `action: "list"` 可携带 `noteId`、`notebookId`。响应包含 `ok`、`token`、`items: [{id, name, site}]`，不包含提示词、上传范围和卡片正文。AI Bridge 持有原卡片校验快照、工作流库版本及可选 ID。
- `action: "run"` 携带上一响应的 `token` 和 `id`。服务端验证窗口、有效期（60 秒）、库版本、单次使用、卡片归属与当前选中状态后，委托既有执行器；`ok` 表示接收执行请求，后续网页或上传错误由 AI Bridge 提示，不代表已经上传成功。
- 失败响应为 `ok: false` 和可读的 `error`。工作流列表不支持写入、编辑或删除。

## 验证

`npm test` 包含原网站入口、新旧大观园域名和菜单交互测试。相邻目录存在 `../Ai Bridge/src/AIBExternalWorkflows.js` 时，额外运行 `test/ai-workflows.test.mjs` 中的两个独立 JS 上下文联动测试；单独检出 Focus Switch 时跳过跨仓库测试。AI Bridge 自己的测试覆盖外部卡片快照进入真实工作流执行器及换卡中止。

本机模拟测试不替代 iPad 真机上的跨插件通知、窗口和网页上传验证。
